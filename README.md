# PetCare — Landing page

Landing page do pet shop PetCare: estética animal, serviços veterinários e produtos.

## Como publicar no GitHub Pages
1. Envie todos os arquivos desta pasta para a raiz do repositório (branch `main`).
2. No GitHub, abra **Settings → Pages**.
3. Em **Source**, escolha `Deploy from a branch`, depois `main` e `/ (root)`, e salve.
4. O site fica disponível em `https://gubarroso.github.io/Familia-PET/`.

## Estrutura
- `index.html` — página principal (os textos, contatos e horários ficam neste arquivo)
- `assets/` — imagens
- `support.js`, `image-slot.js` — scripts de funcionamento da página
